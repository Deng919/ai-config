# AI Config v0.1 设计

日期：2026-11-05。根据用户确认的分享方案建立独立 GitHub 仓库。

## 目标与方案

提供可阅读、可选择安装的 Windows Codex 配置包。采用 Git 仓库维护模板、两个本地个人技能与安装说明；相比一次性 ZIP 更便于更新，相比完整插件市场更适合同时分享配置和规则。

第一版仅附带 direct-output、report-writing；其余第三方技能和官方插件登记来源，不复制整个用户目录。账号、凭据、历史会话、日志、缓存和绝对个人路径不发布。

## 交付内容

- 通用 AGENTS.md：直接表达、简单开发、按风险验证、事实与假设分开。
- 配置及 MCP 示例仅供阅读和手动合并，不自动覆盖 config.toml。
- 安装器支持 Rules / Skills 两个模块、预览、重复运行、已有文件冲突报告和明确选择替换后的备份。
- 不预设自动 GitHub 推送、模型供应商、管理员权限、本地订阅账号或固定盘符。
- 第三方来源清单、官方插件用途、Windows 说明、MIT 许可证。

## 安装边界

默认目标为用户目录内的 .codex 与 .agents/skills；尊重 CODEX_HOME，并允许通过参数指定测试目录。拒绝经过重解析点的目标路径。全量预检后再写入；已有不同文件默认终止，-ReplaceExisting 才备份并替换。备份目录留在 Codex home 内，不进入分享仓库。

## 验证

使用隔离临时用户目录测试首次安装、预览零写入、重复运行、模块选择、冲突前置阻止、替换备份、自定义 Codex home 及路径重定向。检查 TOML/YAML、公开文件中的本机路径和凭据模式，检查待提交文件。
