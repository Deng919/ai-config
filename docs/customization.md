# 根据自己的电脑调整

## 运行环境和文件位置

在自己的全局规则中填写实际 Python 环境、项目目录、下载目录和缓存位置。不要直接套用别人的用户名、盘符或工具路径。

仓库提供的全局规则会优先使用用户或项目已指定的环境；不会创建虚拟环境或安装软件。

## GitHub 自动提交和推送（可选）

如果确实希望助手主动推送，可自行添加：

> 较大功能或重要修复验证后，提交本次变更并推送当前工作分支。不得提交凭据和本地运行数据，不自动合并主分支，不强推。成功后报告分支和提交。

此习惯依赖使用者自己的 GitHub 权限；基础配置遵循每次任务的授权。

## 搜索工具（可选）

可用 AnySearch，也可以使用运行环境已经提供的搜索工具。将偏好写进自己的全局规则，并明确不可用时的替代方式。基础配置没有强制绑定某个搜索提供商。

## 数学和报告（可选）

`report-writing` 负责内容与论证；Word、PDF、演示等文件工作交给已安装的对应插件。数学推导与符号验证可以分别使用 scientific-reasoning、sympy。这些可选技能和插件需要独立安装。

## 图片生成（可选）

采用自己账号和环境支持的图片工具。维护者原环境的本地订阅包装脚本和账号管理目录未包含在仓库中，通用规则没有假定这些服务已存在。

## 浏览器故障经验

维护者曾遇到 Codex 内置浏览器标签操作与客户端退出同时发生，根因未确认。遇到类似情况，可用独立 Chromium/Playwright 进程进行测试，并保留日志。此经验作为故障排查参考，不作为所有人的默认禁用规则。
