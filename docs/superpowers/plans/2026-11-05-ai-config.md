# AI Config Implementation Plan

> **For agentic workers:** Execute this plan task-by-task using the current runtime's native tools. Follow the user's execution preferences and existing authorization. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可公开分享的 Windows Codex 配置仓库。

**Architecture:** 配置模板、两个个人技能、来源清单与独立 PowerShell 安装器。安装器只写选中的规则和技能文件；配置示例手动合并。

**Tech Stack:** Markdown、TOML、JSON、PowerShell 5.1+；Python unittest 驱动隔离安装测试。

**Spec:** docs/design.md

## Global Constraints

- 不发布账号、凭据、聊天、数据库、缓存、绝对个人路径。
- 不覆盖已有不同文件，除非调用者显式指定 -ReplaceExisting；替换前备份。
- 支持 Windows PowerShell 5.1+，不自动安装软件或第三方服务。

## Review Focus

- 预览不创建文件或目录。
- 后续文件冲突不得导致前面的文件已写入。
- 重复运行不得创建无意义备份。
- 自定义 CODEX_HOME 和模块选择不得写错位置。
- 重解析点不得把安装写入重定向到未选择的位置。
