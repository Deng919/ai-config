# 维护与验证

## 更新

拉取仓库更新后，先运行 `install.ps1 -WhatIf`，再选择安装模块。已有不同文件默认停止；确认差异后手动合并，或使用 `-ReplaceExisting` 备份后替换。

保持个人规则与通用模板的差异清晰。第三方技能跟随各自上游更新，官方插件通过客户端更新；不将缓存复制进仓库。

## 本地测试

测试需要 Windows、PowerShell 5.1+ 和 Python 3.11+。仅用 Python 标准库：

```powershell
python -m unittest discover -s tests -v
```

安装测试在仓库 `.test-work` 下创建隔离的临时用户目录，不写真实全局配置。覆盖预览、冲突、备份、重复安装、模块选择、环境路径和目录联接。

## 发布内容

仅从仓库中的明确文件清单提交。检查配置示例是否仍为示例，是否含个人路径、有效密钥或服务授权信息。公开后发现敏感信息时应撤销相应凭据，再处理仓库历史。

v0.1 的验证范围是 Windows 安装器及静态配置。外部服务授权、所有第三方技能的运行和其他系统上的安装不在本版本验证范围内。
